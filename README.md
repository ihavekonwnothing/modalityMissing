# Modality Missing SAR-Optical Water Segmentation

This repository currently releases the core model implementation for our SAR-optical water segmentation work under missing optical modality.

The released model file is:

```text
models/mask_aware_cross_attention_fusion_unet.py
```

The model is a dual-encoder U-Net style architecture with mask-guided fusion, mask-aware cross-attention, and an auxiliary SAR prediction head for optical-missing inference.

The complete training, testing, degradation evaluation, zero-shot transfer evaluation, configuration files, and reproduction scripts will be uploaded after the paper review/submission process is completed.
